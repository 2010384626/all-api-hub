一条命令更新

在 VPS 的项目目录中执行更新脚本。脚本同步上游、构建镜像并重启服务；具体备份与回滚步骤见部署文档。

bash deploy/update.sh

更新在服务器终端执行。若上游产生不兼容变更，需要先处理兼容问题。

Web 版能力边界

  • 账户数据在服务器持久保存
  • 支持 New API 兼容接口与 Sub2API 账户
  • 模型检测支持 UA 与请求头自定义
  • 无浏览器 Cookie 读取、页面注入或标签页联动
  • 站点验证码和反自动化验证需手动处理
  • 其他站点专用适配、渠道管理与用量明细尚未迁移

基于开源项目 All API Hub（AGPL-3.0）与 lm-detector（MIT）。部署和源码说明见仓库中的 WEB_DEPLOYMENT.md。
